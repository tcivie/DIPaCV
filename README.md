# DIPaCV

**D**igital **I**mage **P**rocessing **a**nd **C**omputer **V**ision library in Go

A work-in-progress implementation of computer vision and image processing algorithms covered in TSI's Computer Vision course.

## About

This library implements fundamental CV/IP algorithms including:
- Image filtering and preprocessing
- Segmentation methods
- Image enhancement and restoration
- Morphological operations
- Object recognition and classification

Built as a learning project to solidify understanding of computer vision concepts while exploring Go's capabilities for image processing.

## Status

⚠︎ **Work in Progress** - Algorithms are being added incrementally as the course progresses.
